## Підтверджені розбіжності модуля v1

Відтворено юніт-тестами і окремо прямими викликами `Cart` на Java 21. Позначення M02–M04 відповідають рядкам матриці. Номери GitHub Issues додаються після реєстрації в командному трекері.

| BL | Метод тесту | Вхід | Очікувано | Отримано у v1 | Issue |
|---|---|---|---|---|---|
| BL-10 / BL-40 | `CartTest.addItemRejectsInvalidArguments` | Кількість 100 для нового SKU | `IllegalArgumentException`, кошик збережено | Додано новий рядок із кількістю 100. У прямій перевірці `changeQty(sku, 100)` також прийнято 100. | Очікує реєстрації |
| BL-20 | `CartTest.sameSkuIncreasesQuantity`, `CartTest.sameSkuOverLimitIsRejected` | Повторне додавання: 2 + 3, 97 + 1, 98 + 1, 98 + 2 | Один рядок із кількістю 5, 98 або 99. Для суми 100 — виняток і вихідні 98. | Отримано 3, 1, 1 та 2 відповідно. Винятку для суми 100 немає. | Очікує реєстрації |

У перевіреній версії коду BL-10 і BL-40 використовують спільну перевірку межі. Для BL-20 одна й та сама операція заміни рядка пояснює розбіжності при допустимій сумі й при перевищенні ліміту. Кожну з цих двох причин варто зареєструвати одним Issue і прив’язати всі відповідні тести.

Після підтвердження кількості 5 і завершення оновлення сума рядка та загальний Total становили $70.75. Кошик відкрився на кроці Cart маршруту `/checkout`. Це ручний результат браузера.
