## Інструмент і формат

Діаграми подано в нотації BPMN 2.0. Для відкриття та редагування використовується [bpmn.io](https://demo.bpmn.io).

У метаданих наданого файла `01_order.bpmn` зазначено експортер **bpmn-js**, версія **18.30.1**. Це версія експортера цього файла, а не гарантована поточна версія вебредактора.

Файли `.bpmn` містять вихідні моделі для редагування. Файли `.pdf` призначені для перегляду без редактора BPMN.

## Як відкрити модель

1. Завантажити потрібний файл `.bpmn` із репозиторію. На сторінці файла скористатися кнопкою завантаження вихідного файла.
2. Відкрити [редактор bpmn.io](https://demo.bpmn.io).
3. Перетягнути завантажений файл у вікно редактора або вибрати його через функцію відкриття файла.
4. Для перегляду без редагування відкрити відповідний PDF із таблиці вище.

## Оновлення і рецензування

Після зміни діаграми потрібно зберегти вихідний файл `.bpmn`, оновити відповідний PDF і звірити модель із таблицею елементів бізнес-процесу. У репозиторії слід оновлювати обидва файли, зберігаючи їхні назви.

Протокол рецензування моделей зберігається у [review.md](review.md). Наявність файлів у папці сама по собі не підтверджує проходження рецензування або виконання Definition of Done.

Моделі описують поточні бізнес-процеси з розділу 3.3 каталогу продуктів. Вимоги до нової функції «Програма лояльності і промокоди» наведено окремо в беклозі спринту.
