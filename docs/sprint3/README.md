## 1. Мета та виконана робота

Мета спринту - розробити незалежні тест-кейси на основі виправленої SRS 1.1, провести тестування вебзастосунку «ШопЛайн», задокументувати фактичні результати та зареєструвати виявлені дефекти для подальшої перевірки.

Команда підготувала набір тест-кейсів, погодила покриття вимог, виконала перевірки demo-застосунку, оформила журнал виконання і реєстр дефектів, провела рецензування та незалежний аудит. За повідомленням керівника тестування, правки, узгоджені всередині команди після рецензування, внесено в робочі матеріали.

Виконані перевірки стосувалися реєстрації та входу, відновлення пароля, каталогу, фільтрації, пошуку й сортування товарів, сторінки товару, кошика, оформлення замовлення, обраного та контактної форми.
